## Faster and lighter

R8 is enabled again. The release APK shrinks from 22.4 MiB to 14.4 MB and the dex payload from
23.1 MB to 1.8 MB, which also shortens install and cold start. Gong recordings are now referenced
through generated `R.raw` ids instead of name lookups, so resource shrinking cannot break playback.

## Unlimited sessions

The circle now shows elapsed / ∞ during unlimited sessions (and ∞ while idle), matching the
elapsed / total display of finite sessions. The hand-painted infinity tally below is unchanged.

## Painting

- Finished strokes are composited once into an offscreen layer. Drawing cost no longer grows with
  the total amount of ink; only the stroke currently under the finger is redrawn.
- Painter control icons are cached per density and rendered at their real display size, so opening
  the canvas no longer rasterizes them on the UI thread and they stay sharp on high-density screens.

## Smoother timer screen

- The 250 ms clock no longer recomposes the whole screen: only the time readout and the repetition
  tally update, once per second.
- Scroll-driven circle bounds no longer invalidate composition.
- Artwork metadata is cached in memory; the 30 s disk poll is gone and the daily state refreshes on
  foreground return and on date, time and timezone changes.

## Hardcore mode

Activation is now a persisted pending flag instead of a wall-clock timestamp comparison. Clock or
timezone changes can no longer demand a second painting or delay the daily rollover. The SPEC
describes the flag.

## Also included

- Settings defaults come from one mapper, so fresh and restored installs cannot diverge.
- The app falls back to the standard artwork and a warning instead of staying blank when artwork
  loading or local state initialization fails.
- Instrumented tests restore settings after every run.
- Unused template launcher icons were removed.
- Release-signed APK, `versionCode 14`, `versionName 1.7.0`.

## Known limits

- A single very long stroke can still drop frames on slower devices. Completed ink no longer adds
  cost, but the active stroke is redrawn from its full dab list.
- The UI remains portrait-only; Android 16+ ignores that lock on displays with a smallest width of
  600 dp or more (tablets, foldables, freeform windows). The painting canvas now fits those windows.
